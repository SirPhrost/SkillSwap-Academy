# Short Demo Video Script

1. Open the home, About, and How It Works pages.
2. Open Workshops and demonstrate keyword search, category/level filters, sorting, and pagination.
3. Log in as Instructor and intentionally submit an invalid workshop form to show validation.
4. Submit a valid workshop and show the saved detail page, then restart the app if time permits to show file database persistence.
5. Register a new Student account, log in, and show that the Student cannot access `/admin` or the workshop creation page.
6. Log in as Admin and edit/delete a workshop.
7. Start the verification microservice and show its protected REST API using Basic Auth.
8. In the Admin dashboard, add a verification record and show it returned from the remote service.
9. Stop the microservice, refresh the Admin page, and show the warning while the primary app continues working.
10. Briefly show `application-dev.yml`, `application-qa.yml`, and `docker-compose.yml`.
